LOVE ADVENTURE — PROGRAM ULANG TAHUN
===================================

ISI FOLDER
- index.html : struktur halaman dan semua layar permainan.
- style.css  : desain, tata letak, animasi, dan tampilan responsif.
- script.js  : alur permainan, gerakan karakter, misi, poin, dan hadiah.
- foto/      : tempat foto kenangan (perlu dibuat sendiri).
- musik/     : tempat musik latar (opsional, perlu dibuat sendiri).

CARA MENJALANKAN
1. Ekstrak ZIP ke folder yang mudah ditemukan.
2. Buka folder di Visual Studio Code.
3. Jalankan index.html dengan ekstensi Live Server, atau buka file itu langsung di browser.
4. Internet hanya diperlukan jika ingin memuat font dari Google Fonts. Game inti berjalan secara lokal.

PERSONALISASI
Buka script.js dan edit bagian CONFIG di paling atas:
- nama dan dari: nama pasangan dan nama pengirim.
- judul dan subjudul: tulisan halaman pembuka.
- cerita: judul, teks, dan nama file foto kenangan.
- soal: pertanyaan, pilihan jawaban, indeks jawaban benar (dimulai dari 0), serta pesan.
- game: target hati dan batas waktu permainan menangkap hati.
- kado: tiga alasan personal yang akan dibuka di akhir.
- suratJudul dan surat: judul dan isi surat ulang tahun.

FOTO DAN MUSIK
Buat folder foto lalu masukkan empat gambar dengan nama 1.jpg, 2.jpg, 3.jpg, dan 4.jpg.
Buat folder musik lalu masukkan lagu.mp3 untuk musik latar. Musik bersifat opsional.

FITUR GAME
1. Level 1 — membaca kenangan hubungan.
2. Level 2 — menjelajahi peta dengan tombol panah/WASD atau tombol arah di layar.
   Kumpulkan lima hati dan buka portal untuk melanjutkan.
3. Bonus quiz — jawab pertanyaan kenangan; jawaban salah bisa dicoba lagi.
4. Level 3 — tangkap 12 hati sebelum waktu habis.
5. Level 4 — cocokkan enam pasang kartu.
6. Level 5 — temukan kunci di salah satu peti.
7. Final — tiup lilin, baca surat, lalu buka tiga alasan spesial.

CATATAN
- Jawaban kuis, foto, nama, dan surat masih contoh. Sesuaikan agar cocok dengan kisah kalian.
- Program ini menggunakan HTML, CSS, dan JavaScript tanpa framework tambahan.
